# Блокопад

Браузерная головоломка с блоками на поле 8×8.

## Как играть
- Перетаскивайте фигуры на поле мышью или пальцем.
- Заполненные ряды и столбцы исчезают. Игра заканчивается, когда ни одна фигура не помещается.
- Клавиатура: 1–3 выбирают фигуру, стрелки двигают, Enter ставит, Esc отменяет.

## Комбо и очки
- На следующую очистку даётся 3 хода, после очистки всего поля 6.
- Множитель растёт на 0,35 за каждую очистку в серии.
- За чистое поле даётся бонус 500 + 50 × комбо.

## Темы
Базовая, Кристалл, Плюш, Неон, Конфеты, Дерево, у каждой свои звуки.
Тема меняется после очистки всего поля, 3 линий за ход и на комбо 5, 10, 15…

## Запуск
Откройте `index.html` в браузере. Сборка не нужна.
Рекорд и текущая партия сохраняются в браузере. Шрифты загружаются из Google Fonts.
